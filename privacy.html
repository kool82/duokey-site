Kanagul プライバシーポリシー

日本語 · 한국어 · English · 2026-10-24

日本語

Kanagul は入力の処理を端末内で行います。入力した文章を外部へ送信せず、ネットワーク通信、広告、アクセス解析、アカウント登録を使用しません。開発者が利用者の情報を収集することはありません。

キーボードは入力と変換のために、入力中の文字や iOS から提供される入力欄の前後の文章を扱います。入力履歴は保存しません。日本語のかな漢字変換で選んだ候補は、次から上位に出るよう学習データとしてキーボード内にのみ保存されます。韓国語と英語で続けて入力した2つの単語の組み合わせも、次の単語の候補のためにキーボード内にのみ保存されます（メールアドレス・URL の欄を除く）。学習はキーボード設定でオフにでき、「学習をリセット」で削除できます。iPhone のユーザ辞書は読み取るだけで、変更や保存はしません。配列などの設定は端末内に保存されます。

文字入力に「フルアクセス」は不要です。キーの振動を使う場合のみ任意で許可でき、許可しても入力内容を送信する処理はありません。

Kanagul を削除すると、端末内の設定と学習データも削除されます。お問い合わせは GitHub Issues へ。

한국어

Kanagul은 입력 처리를 기기 안에서 수행합니다. 입력한 글을 외부로 전송하지 않으며, 네트워크 통신, 광고, 분석, 계정 등록을 사용하지 않습니다. 개발자는 이용자의 정보를 수집하지 않습니다.

키보드는 입력과 변환을 위해 입력 중인 글자와 iOS가 제공하는 입력란 앞뒤의 글을 다룹니다. 입력 기록은 저장하지 않습니다. 일본어 가나·한자 변환에서 선택한 후보는 다음에 위쪽에 나오도록 학습 데이터로 키보드 안에만 저장됩니다. 한국어와 영어로 이어서 입력한 두 단어의 조합도 다음 단어 후보를 위해 키보드 안에만 저장됩니다(이메일 주소·URL 입력란 제외). 학습은 키보드 설정에서 끌 수 있고 「Reset Learning」로 삭제할 수 있습니다. iPhone 사용자 사전은 읽기만 하며 변경하거나 저장하지 않습니다. 배열 등의 설정은 기기 안에 저장됩니다.

글자 입력에 '전체 접근 허용'이 필요하지 않습니다. 키 진동을 사용할 때만 선택적으로 허용할 수 있으며, 허용해도 입력 내용을 전송하는 처리는 없습니다.

Kanagul을 삭제하면 기기 안의 설정과 학습 데이터도 삭제됩니다. 문의는 GitHub Issues로 보내 주세요.

English

Kanagul processes everything you type on your device. It does not send your text anywhere and uses no network connections, ads, analytics or accounts. The developer collects no information about you.

To input and convert text, the keyboard handles the characters you are typing and the surrounding text iOS provides. It does not keep a typing history. Japanese conversions you choose are stored as learning data only inside the keyboard so they rank higher next time, and pairs of consecutive Korean or English words are stored there too for next-word suggestions (not in email or URL fields); you can turn learning off or reset it in the keyboard settings. Your iPhone user dictionary is read only. Layout settings are stored on the device.

Full Access is not required for typing. You may allow it only for key haptics; even then, nothing you type is sent.

Deleting Kanagul removes its settings and learning data from your device. Contact: GitHub Issues.
