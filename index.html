サポート

Kanagul は日本語・韓国語・英語を切り替えて入力できる iPhone / iPad 用キーボードです。

使い始め方：「設定」→「一般」→「キーボード」→「キーボード」→「新しいキーボードを追加…」で Kanagul を選び、入力欄で地球儀キーを長押しして Kanagul に切り替えます。言語キー「あ한A」のタップで言語を切り替え、長押しで配列や設定を変更できます。

よくある質問
・パスワード欄では iOS の標準キーボードに切り替わります（iOS の仕様）。
・文字入力にフルアクセスは不要です。キーの振動を使う場合のみ許可してください。
・iOS の制限で、他社製キーボードには音声入力キーがありません。

お問い合わせ：GitHub Issues からお送りください。

지원

Kanagul은 한국어·일본어·영어를 바꿔 가며 입력할 수 있는 iPhone / iPad용 키보드입니다.

시작하기: 「설정」→「일반」→「키보드」→「키보드」→「새로운 키보드 추가...」에서 Kanagul을 선택한 뒤, 입력란에서 지구본 키를 길게 눌러 Kanagul로 전환하세요. 언어 키 「あ한A」를 탭하면 언어가 바뀌고, 길게 누르면 배열과 설정을 바꿀 수 있습니다.

자주 묻는 질문
・암호 입력란에서는 iOS 기본 키보드로 전환됩니다(iOS 사양).
・글자 입력에 전체 접근 허용이 필요하지 않습니다. 키 진동을 사용할 때만 허용하세요.
・iOS 제한으로 타사 키보드에는 음성 입력 키가 없습니다.

문의: GitHub Issues로 보내 주세요.

Support

Kanagul is a keyboard for iPhone and iPad that switches between Japanese, Korean and English.

Getting started: Settings → General → Keyboard → Keyboards → Add New Keyboard… → Kanagul. In any text field, long-press the globe key and choose Kanagul. Tap the language key "あ한A" to switch languages; long-press it for layouts and settings.

FAQ
・Password fields always use the iOS system keyboard.
・Full Access is not needed for typing. Allow it only if you want key haptics.
・iOS does not give third-party keyboards a dictation key.
